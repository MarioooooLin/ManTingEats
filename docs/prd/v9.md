# PRD — ManTingEats v9（營業日 06:00 切換）

> 狀態：**已定案**（2026-10-07，使用者決議切換時間為 06:00）。本文件調整 [mvp.md](mvp.md) 的每日流水號與營收報表的「日」定義。

## 1. 需求摘要

**背景**：營業時間 17:00–02:00，每天都會跨過午夜。原本以台灣時間 00:00 切日，造成：

- 每日流水號在 00:00 歸零，00:00–02:00 出現第二組 #1、#2…，與尚未出完餐的單撞號。
- 營收報表把同一晚的營收拆成兩天。

**目標**：以「營業日」取代日曆日，**06:00 切換**；06:00 前的時間都算前一天的營業日。

## 2. 規則

| 台灣時間 | 所屬營業日 |
| --- | --- |
| 10/8 17:00 | 10/8 |
| 10/8 23:59 | 10/8 |
| 10/9 01:30 | 10/8 |
| 10/9 05:59 | 10/8 |
| 10/9 06:00 | 10/9 |

選 06:00 的原因：打烊（02:00）後留足收尾、補結帳的緩衝，且早於每日 08:00 的自動備份。

## 3. 影響範圍

- **每日流水號**：本營業日內最大號 + 1，06:00 才從 1 重新開始。
- **營收報表**：選擇某日 = 該日 06:00 至隔日 06:00 之間**結帳**的訂單；「今日／本週／本月」快捷按鈕以目前營業日計算（例如 01:00 按「今日」看到前一晚 17:00 起的營收）。

**不變**：

- 訂位：顧客指定的實際日期時間，依日曆日。
- 支出：手動填寫日期，報表依支出日期加總。
- 出單紙上的列印時間：實際時間。

## 4. 驗收標準

- 06:00 前建立的訂單延續前一營業日的單號；06:00 後第一張單為 #1。
- 凌晨結帳的訂單計入前一營業日的報表。
- 無資料庫結構變更（不需 Migration）。
