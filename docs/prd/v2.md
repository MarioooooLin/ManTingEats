# PRD — ManTingEats v2（支出記錄模組）

> 狀態：**已定案**（2026-09-21）。本文件為 [mvp.md](mvp.md) 的擴充版本，僅新增「支出記錄（Expense）」模組，不修改 MVP 既有範圍。

## 1. 需求摘要

**目標**：讓店長可以隨手記錄營運支出，並在既有營收報表中同步顯示「淨利」，取代目前完全沒有支出資料的狀態。

**使用者情境**：目前僅店長一人操作，記錄頻率不固定（想到就記），非每日固定流程。

## 2. 模組詳細規格

### 2.1 支出記錄（Expense）

**使用者故事**

- As a 店長, I want 隨手記錄一筆支出（分類、金額、日期、備註）, so that 事後能知道錢花在哪，也能算出淨利。
- As a 店長, I want 編輯或刪除記錯的支出, so that 帳目資料保持正確。
- As a 店長, I want 在營收報表中同時看到支出與淨利, so that 不用自己拿計算機加減。

**驗收標準**

- 欄位：
  - 日期（必填，預設今天，可修改）
  - 分類（必選，固定下拉選單，見 2.2）
  - 金額（必填，`decimal` 型別，須 > 0，禁止 `float`/`double`）
  - 備註（選填，自由文字，長度上限比照現有 Command 的 `[StringLength]` 慣例）
- 功能：新增、列表查詢（可依日期區間、分類篩選）、編輯、刪除。
- 刪除/編輯**不需要**像訂單作廢一樣記錄操作者與原因（單一店長操作、非高風險金流異動，降低複雜度）。
- Report 模組串接：既有日期區間查詢（今日/本週/本月/自訂）新增：
  - 本期支出總額
  - 淨利 = 本期營收（僅計已結帳訂單）− 本期支出總額

### 2.2 支出分類（固定清單，不開放使用者自訂）

| 分類 | 說明 |
| --- | --- |
| 食材採購 | 買菜、買肉、飲料原料等 |
| 水電瓦斯 | 水費、電費、瓦斯費 |
| 房租 | 每月店租 |
| 人事薪資 | 員工薪水、加班費 |
| 設備/耗材 | 餐具、包材、清潔用品、小型設備維修 |
| 其他 | 不屬於以上的雜項支出 |

> 分類清單先固定，避免自由輸入造成報表統計失真；未來若需增修分類，屬於資料遷移工作，需另行規劃既有資料的分類調整。

## 3. 明確排除（本次不做）

- 不記錄供應商資訊。
- 不與菜單品項/庫存建立關聯（避免提前踩入 MVP 已排除的「庫存管理」範圍）。
- 不做預算控管、審核流程、多角色簽核（單一店長操作情境下無需要）。
- 不做刪除/編輯的操作稽核紀錄（與訂單作廢的高風險稽核需求不同）。

## 4. 已識別風險與因應

| 風險 | 因應 |
| --- | --- |
| 固定分類清單可能不符合實際記帳習慣 | 上線前已與店長確認分類項目；若後續需調整，需評估既有資料的分類遷移成本 |
| 支出無稽核紀錄，可能被誤刪且無法追溯 | 現階段風險可接受（金額小、單一操作者），待未來多角色需求明確後再評估是否加稽核 |
