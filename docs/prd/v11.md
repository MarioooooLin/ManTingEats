# PRD — ManTingEats v11（訂單列表只顯示今天＋查詢）

> 狀態：**已定案**（2026-10-10）。本文件取代 MVP 起訂單列表「所有訂單、未結帳排最前、每頁 20 筆」的規則。

## 1. 需求摘要

**背景**：訂單列表原本混列所有日期的訂單，開幕後舊單越來越多；單號每天從 1 開始，跨日會出現多張同號的單，不易辨識。

> 2026-10-10 修訂：查詢原本有「單一營業日＋單號」，改為營業日區間、不提供單號查詢（使用者：單號都是 1、2、3 這類小數字，查詢價值低）。

**目標**：訂單頁平常只看今天營業日的最新訂單；要找舊單時用查詢。

## 2. 規則

### 預設畫面（未帶查詢條件）

- 只顯示**今天營業日**（06:00 切換，見 [v9.md](v9.md)）**最新 10 筆**，依建立時間倒序，不分頁。
- 不論結帳狀態，一律依時間排序（取消「未結帳排最前」）。
- **未結帳提示**：表格上方提示所有尚未結帳的張數（含今天與以前營業日，「有 N 張訂單尚未結帳」），不列出訂單；需處理時以「狀態：未結帳」查詢。沒有時不顯示。
- 提示可關閉，但不記住：重新整理或回到訂單頁會再出現。

### 查詢

| 條件 | 說明 |
| --- | --- |
| 營業日區間 | 開始、結束營業日（含當天；開始日 06:00 至結束日隔天 06:00）；兩欄預設帶入今天，留空代表該端不限 |
| 狀態 | 全部／未結帳／已完成／已作廢 |

- 條件可任意組合；結果依建立時間倒序，**每頁 10 筆**分頁。
- 「清除」回到預設畫面。

## 3. 已知限制

- 今天超過 10 張單時，今天較早開、尚未結帳的單不在預設畫面（提示張數仍會算入），需以「狀態：未結帳」查詢。
- v9 以前（午夜切日）建立的訂單，同一營業日內可能有重複單號。
