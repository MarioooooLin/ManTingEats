# PRD — ManTingEats v16（外帶點完即結帳）

> 狀態：**已定案**（2026-10-13，使用者選方案一）。結帳視窗沿用 [v6.md](v6.md)（收款／找零）與 [v8.md](v8.md)（折扣）；「結帳前必須出完單」沿用 [v5.md](v5.md)。

## 1. 需求摘要

**背景**：外帶客人點完餐就付款，但目前出單後還要另外按「結帳」，與內用（用餐後結帳）的流程相同，多一個步驟。

**目標**：外帶單出單成功後，**自動打開結帳視窗**；店員直接「收剛好」或輸入收款金額即可完成。

## 2. 規則

- 觸發條件：**外帶**、未結帳，且出單成功後**已無待出單品項**。由出單成功的處理（`MarkPrinted`）帶一次性標記，回到訂單頁時自動打開結帳視窗。
- 順序維持「點餐 → 出單 → 結帳」：出單失敗不會跳出結帳視窗，依 v5 處理印表機後重新出單。
  - 未採「先結帳再出單」（方案二）：需放寬「結帳前必須出完單」，並處理結帳後才出單失敗（已結帳訂單鎖定、無法再出單），改動與風險大。
- 結帳視窗本身不變（收款、找零、折扣）；不想結帳（例如客人還要加點）關掉視窗即可，訂單維持未結帳。
- 標記讀一次即消失，重新整理訂單頁不會再跳出。
- **內用不變**：出單後不跳結帳視窗。
- **手機點的外帶單**：手機不出單（v14），因此不會跳出；到 iPad 按「確認訂單」出單成功後，結帳視窗在 iPad 上跳出。

## 3. 影響範圍

| 位置 | 變更 |
| --- | --- |
| 後端 `MarkPrinted` | 外帶且已出完單時設定 `TempData["AutoCheckout"]` |
| 訂單詳情頁 | 有標記時自動打開結帳視窗 |

## 4. 資料

- 不需 Migration。

## 5. 驗收標準

- 外帶單送出並出單成功後，回到訂單頁即跳出結帳視窗，可直接收款結帳。
- 內用單出單後不跳出結帳視窗。
- 出單失敗、或仍有待出單品項時不跳出。
- 重新整理訂單頁不會再跳出。
