# PRD — ManTingEats v13（日結）

> 狀態：**已定案**（2026-10-10）。新增「日結」功能，不修改既有模組的規則；營收與支出的算法沿用營收報表（[v9.md](v9.md) 營業日、[v12.md](v12.md) 支出營業日）。

## 1. 需求摘要

**背景**：店長每天打烊會點收收銀機與抽屜的現金，但系統只有營收報表，無法對帳，也沒有留下紀錄。開店時收銀機與抽屜共放零用金 $15,000；目前只收現金，支出也全部從抽屜付現金。

**目標**：打烊時在系統上完成現金對帳並保存紀錄，事後可查每天的差額與經手人。

## 2. 規則

### 日結畫面（店長、員工皆可使用）

- 預設為目前營業日（06:00 切換）；可選擇過去的營業日補做，不可選未來。
- **有未結帳訂單時不能日結**：範圍為到該營業日為止開立、尚未結帳的訂單（含前幾天遺留的），畫面列出並可直接前往結帳或作廢。
- 顯示當日彙總：已結帳張數、作廢張數（依開單時間）、折扣總額、營收（實收）、支出。
- 現金對帳：

  ```
  應有現金 = 零用金 + 營收 − 支出
  差額     = 實點現金 − 應有現金（正數為「多」、負數為「少」）
  ```

- 零用金預設 $15,000（設定 `DailyClosing:DefaultOpeningCash`），日結時可修改；重新日結時沿用上次填的金額。
- 實點現金只輸入總金額（整數）；備註選填，最多 200 字。

### 重新日結

- 已日結的營業日可重新日結，**原因必填**；每次日結都另存一筆，以最後一次為準。
- 營收、支出等數字在日結當下存成快照，之後資料變動不影響舊紀錄。

### 日結紀錄（僅店長）

- 每個營業日一列，顯示最後一次日結的營收、支出、應有現金、實點、差額、日結人與日結次數；每頁 10 筆。
- 明細頁列出該營業日每一次日結的完整內容與原因。

## 3. 已知限制

- 作廢訂單沒有記錄作廢時間，作廢張數以開單時間判斷所屬營業日。
- 員工無法新增支出；員工日結後若店長補登當日支出，需由店長重新日結。
- 不支援非現金收款或非現金支出；日後新增其他付款方式時需調整公式。
